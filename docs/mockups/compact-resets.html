Option A: two-line cells recommended

  • Still fits in the 48px bar. Each limit gets its own cell: label and percent on top, bar and reset countdown below.
  • Claude gets three cells: Session, Weekly (all models), Fable. ChatGPT gets two, or one when Codex only reports weekly. Grok gets its shared pool.
  • As the bar narrows, the note, theme button, and Full link go first. Then labels and resets shorten (Session → 5h, 2h 14m → 2h), then the bars go. Numbers and resets stay visible.

Option B: single-line segments

  • Everything on one line per limit: Session ▬ 42% ↻ 2h 14m. Easier to scan, but it needs about 1300px to show the bars.
  • At the default 980px the bars are already gone, so it's close to Option A without the visual meter.
